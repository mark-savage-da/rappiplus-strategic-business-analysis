# RappiPlus Strategic Business Analysis

Power BI and Python project focused on e-commerce commercial performance, profitability, marketing investment, conversion, customer retention, experimentation, and product analysis.

## Project Status

This repository contains the approved project notebook, the Power BI dashboard, and the cleaned datasets used in the analysis.

## Project Overview

This project analyzes the commercial performance of RappiPlus through customer orders, product costs, marketing investment, conversion behavior, cohort retention, A/B testing, and product-level results.

## Business Relevance

This project is especially relevant for Business Intelligence and Marketing Data Analytics because it connects e-commerce transactional, behavioral, and marketing data with executive and commercial decision-making.

## Current Files

- `rappiplus-strategic-business-analysis.ipynb`: approved project notebook with data preparation, profitability analysis, SQL queries, conversion funnel, cohort retention, A/B testing, business interpretation, and evaluator feedback
- `rappiplus-powebi-dashboard.pbix`: Power BI dashboard file with executive overview, financial indicators, commercial analysis, product performance, filters, navigation, and drill-through analysis
- `orders_clean.csv`: cleaned transactional and customer order data
- `catalog_clean.csv`: cleaned product catalog, category, cost, and supplier data
- `marketing_clean.csv`: cleaned marketing investment data by date, country, campaign, and channel
